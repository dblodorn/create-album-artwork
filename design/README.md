# dmbk design

The shared visual language of the dmbk apps (album artwork first, dmbk-photo next): the FFF typeface at application sizes, a monochrome Reshaped theme with square containers, small pill buttons, italic tooltips, and light / dark / system colour modes.

The folder is self-contained. Nothing in it imports app code (`boundary.test.ts` enforces that), so it can be copied into another app, or turned into a package later.

## What's here

| File | What it is |
|---|---|
| `reshaped.config.mjs` | The `dmbk` Reshaped theme: monochrome colour ramp (light and dark), radii 0, every font family `var(--font-fff)` plus fallbacks, Reshaped's default type scale. |
| `themes/dmbk/` | The compiled theme (`theme.css`, `media.css`, `theme.json`). Generated by `npm run theme`, but checked in, so builds never run the generator. |
| `tokens.css` | The few tokens the theme has no slot for (`--dmbk-*`: pill size, image overlays, checkerboard, workspace, document shadow) and the `.dmbk-pill` / `.dmbk-hint` classes. |
| `fonts/`, `fonts.ts` | FFF Regular and Italic (`.woff`), loaded with `next/font/local` as one family, exposed as `--font-fff`. |
| `colorMode.ts` | Pure colour-mode rules: choices, storage key, `resolveMode`, and `COLOR_MODE_SCRIPT` (the inline pre-paint script). |
| `ColorModeProvider.tsx` | `<Reshaped>` with the theme and a controlled colour mode; `useColorMode()` → `{ choice, mode, setChoice }`. |
| `Pill.tsx` | The text button. |
| `Hint.tsx` | The tooltip, plus `mergeTriggerAttributes` for one button that triggers both a Hint and a Popover. |
| `index.ts` | The public surface. |

## Wiring it into an app

1. **Theme script.** Add `"theme": "reshaped theming --config design/reshaped.config.mjs --output design/themes"` and the `@reshaped/theming` devDependency (same major as `reshaped`).
2. **PostCSS.** Reshaped's component CSS uses custom media that must be inlined from the theme:

   ```js
   import path from 'node:path'
   import { getConfig } from 'reshaped/config/postcss'
   export default getConfig({ themeMediaCSSPath: path.join(process.cwd(), 'design/themes/dmbk/media.css') })
   ```

3. **Root layout** (a server component). Import constants from `design/colorMode`, not the barrel file (that re-exports client modules):

   ```tsx
   import { COLOR_MODE_SCRIPT, FALLBACK_MODE, THEME } from '@/design/colorMode'
   import { fff } from '@/design/fonts'
   import '@/design/themes/dmbk/theme.css'
   import '@/design/tokens.css'

   <html className={fff.variable} data-rs-theme={THEME} data-rs-color-mode={FALLBACK_MODE} suppressHydrationWarning>
     <head><script dangerouslySetInnerHTML={{ __html: COLOR_MODE_SCRIPT }} /></head>
   ```

   Reshaped sets these attributes only after mount, so they must be server-rendered. The script swaps in the stored choice, or the system's, before first paint.
4. **Provider.** Wrap the client tree in `<ColorModeProvider>` in place of `<Reshaped>`.
5. **Components.** Use `Pill` for text buttons and `Hint` for every tooltip, never Reshaped's `Tooltip` directly. Copy `usage.test.ts` to keep that true. Icon-only buttons are Reshaped `Button`s with `rounded`.
6. **A colour-mode control.** Call `useColorMode().setChoice('light' | 'dark' | 'system')`, for example from a menu with `role="menuitemradio"` items.

## Notes

- **Colour mode.** The choice lives in `localStorage['dmbk-color-mode']`, per browser. System is the default and follows the OS live; other open tabs follow a change. Blocked storage falls back to System silently. Reshaped 4.1 doesn't write `<html>`'s attribute for a controlled mode, so the provider does.
- **CSP.** `COLOR_MODE_SCRIPT` is inline. If the app adds a Content-Security-Policy, give it a nonce or hash, or the page will paint the fallback mode until hydration.
- **FFF glyphs.** FFF has no ⌘ ⇧ ⌥ or arrow glyphs. The font stack's fallbacks draw them, glyph by glyph.
- **FFF has one weight** (400). Bold text is synthesised by the browser.

## FFF licence

FFF is a commercial face by Luzi Type. Its licence (embedded in the font files) allows web use only through self-hosted `@font-face`, covers **one domain per licence**, and forbids **converting the files to other formats**: serve the `.woff` files as they are, with no woff2 or subsetting. Each app or domain that uses this folder needs its own web licence. The originals live in the owner's font library (`--FONTS/FFF`).
